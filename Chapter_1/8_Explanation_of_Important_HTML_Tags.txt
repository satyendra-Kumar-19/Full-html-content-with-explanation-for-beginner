------------------------------------------------------------
8. EXPLANATION OF IMPORTANT HTML TAGS
------------------------------------------------------------

8.1 <!DOCTYPE html>
-------------------

PURPOSE:
Declares that the document uses modern HTML.

EXAMPLE:

<!DOCTYPE html>

IMPORTANT FACTS:

- It is a document type declaration, not a normal HTML element.
- It should appear at the beginning of an HTML document.
- It helps browsers use standards mode rather than quirks mode.
- It is not an opening tag and does not require a closing tag.
- Modern HTML uses this short declaration.

WITHOUT IT:

Some browsers may render the page in quirks mode, where
certain older layout and rendering behaviors are used.

BEST PRACTICE:

Always include <!DOCTYPE html> at the beginning of the file.


8.2 <html>
-----------

PURPOSE:
The <html> element is the root element of an HTML document.

EXAMPLE:

<html lang="en">
    <!-- The document's head and body go here -->
</html>

IMPORTANT FACTS:

- It contains the document's head and body.
- It is the root of the document's HTML structure.
- It commonly includes the lang attribute.
- A normal HTML document has one root html element.

UNDERSTANDING lang="en":

The lang attribute identifies the primary language of the
document's content.

Examples:

<html lang="en">    English
<html lang="hi">    Hindi
<html lang="fr">    French

WHY IS IT IMPORTANT?

It helps assistive technologies, search engines, and other
software interpret the language of the page.

NOTE:

The language code should match the primary language of
your document.


8.3 <head>
----------

PURPOSE:
Contains metadata and resources associated with the document.

EXAMPLE:

<head>
    <meta charset="UTF-8">
    <title>My Website</title>
</head>

COMMON CONTENTS OF HEAD:

- Document title
- Character encoding
- Viewport settings
- Search-related metadata
- CSS stylesheet links
- Favicons
- Some scripts and other resources

IMPORTANT FACTS:

- The head is not the main visible content area of the page.
- Its contents provide information about the document or
  resources needed by the browser.
- The title may appear in the browser tab.
- The head is different from the header element.

IMPORTANT DISTINCTION:

<head> = Document metadata and resources.

<header> = A visible structural section of a page or section,
           commonly containing introductory content or
           navigation.


8.4 <meta>
----------

PURPOSE:
Provides metadata about the HTML document.

A meta element does not use a separate closing tag.

COMMON EXAMPLE 1: CHARACTER ENCODING

<meta charset="UTF-8">

PURPOSE:
Specifies the character encoding used by the document.

UTF-8 supports text from a wide range of writing systems.

It helps the browser interpret characters correctly.

COMMON EXAMPLE 2: VIEWPORT

<meta name="viewport" content="width=device-width, initial-scale=1.0">

PURPOSE:
Helps the page use the device's viewport width and an
appropriate initial scale on mobile devices.

WITHOUT APPROPRIATE VIEWPORT SETTINGS:

A page may not behave as expected on mobile screens.

COMMON EXAMPLE 3: DESCRIPTION

<meta name="description" content="Learn the basics of HTML.">

PURPOSE:
Provides a short description of the page.

Search engines may use this description when displaying
search results, but they are not required to do so.

IMPORTANT:

Metadata provides information about a document; it does not
automatically guarantee better search rankings.


8.5 <title>
-----------

PURPOSE:
Defines the document's title.

EXAMPLE:

<title>HTML Chapter 1</title>

WHERE DOES IT APPEAR?

- Commonly in the browser tab
- In bookmarks and saved page references
- Potentially in search result titles, depending on the
  search engine

IMPORTANT FACTS:

- The title belongs inside the head element.
- It is not the same as a visible heading.
- It should describe the page clearly.
- A document should have one meaningful title.

COMPARISON:

<title>My Website</title>

This sets the document title.

<h1>Welcome to My Website</h1>

This creates a visible main heading in the page content.


8.6 <body>
-----------

PURPOSE:
Contains the main content of the HTML document.

EXAMPLE:

<body>
    <h1>My First Website</h1>
    <p>Welcome to my website.</p>
</body>

COMMON BODY CONTENT:

- Headings
- Paragraphs
- Images
- Links
- Lists
- Tables
- Forms
- Navigation
- Videos

IMPORTANT FACTS:

- The body contains the document's main visible content.
- A standard HTML document has one body element.
- Most content that users read or interact with belongs here.

REMEMBER:

<head> describes the document and its resources.

<body> contains the page's main content.


8.7 <h1> TO <h6>
----------------

PURPOSE:
Represent six levels of headings.

EXAMPLE:

<h1>Main Heading</h1>
<h2>Section Heading</h2>
<h3>Subsection Heading</h3>
<h4>Level Four Heading</h4>
<h5>Level Five Heading</h5>
<h6>Level Six Heading</h6>

HEADING LEVELS:

<h1> = Highest heading level
<h2> = Second heading level
<h3> = Third heading level
<h4> = Fourth heading level
<h5> = Fifth heading level
<h6> = Lowest heading level

BEST PRACTICE:

Use heading levels to represent the hierarchy of your content.

For example:

<h1>HTML Tutorial</h1>

<h2>Introduction</h2>
<p>Introduction content...</p>

<h2>HTML Elements</h2>
<p>Element-related content...</p>

<h3>Void Elements</h3>
<p>Void element content...</p>

IMPORTANT:

Do not choose a heading level only because of its default
font size. CSS should control visual styling.


8.8 <p>
--------

PURPOSE:
Defines a paragraph.

EXAMPLE:

<p>HTML structures content on a web page.</p>

IMPORTANT FACTS:

- A paragraph is a block of text content.
- Browsers commonly display paragraphs as separate blocks.
- Browsers normally provide spacing around paragraphs.
- CSS can change their appearance and spacing.

NOTE:

Browsers may automatically close a paragraph when the HTML
rules require it, but beginners should always write clear,
well-structured markup.


8.9 <br>
---------

PURPOSE:
Creates a line break within text.

EXAMPLE:

<p>
    First line<br>
    Second line
</p>

OUTPUT:

First line
Second line

IMPORTANT FACTS:

- <br> is a void element.
- It does not require a closing tag.
- Use it when a line break is meaningful.

Do not use repeated <br> elements to create large amounts
of spacing. Use CSS for layout and spacing instead.


8.10 <hr>
----------

PURPOSE:
Represents a thematic break between sections of content.

EXAMPLE:

<p>Introduction to HTML.</p>
<hr>
<p>Introduction to CSS.</p>

IMPORTANT FACTS:

- It is a void element.
- It often appears as a horizontal line by default.
- Its meaning is a thematic break, not merely decoration.

CSS can change its visual appearance.


8.11 <!-- Comment -->
--------------------

PURPOSE:
Adds a comment to the HTML source code.

EXAMPLE:

<!-- This is a comment -->

<h1>Welcome</h1>

IMPORTANT FACTS:

- Comments are not displayed as ordinary page content.
- They help developers explain sections of code.
- They can be used to temporarily annotate code.
- They begin with <!-- and end with -->.

WARNING:

Do not put passwords, secret keys, or private information
inside HTML comments. Source code can be viewed by users.
