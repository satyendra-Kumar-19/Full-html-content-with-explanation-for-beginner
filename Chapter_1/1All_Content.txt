10. TYPES OF HTML ELEMENTS
------------------------------------------------------------

HTML elements can be classified in several ways.

A. ELEMENTS WITH OPENING AND CLOSING TAGS

These elements commonly contain text or other elements.

EXAMPLES:

<p>This is a paragraph.</p>

<h1>Main Heading</h1>

<div>Container content</div>

B. VOID ELEMENTS

Void elements cannot contain child elements and do not have
closing tags.

COMMON VOID ELEMENTS:

- <area>
- <base>
- <br>
- <col>
- <embed>
- <hr>
- <img>
- <input>
- <link>
- <meta>
- <source>
- <track>
- <wbr>

EXAMPLE:

<img src="photo.jpg" alt="A photograph">

CORRECT:

<br>
<hr>
<img src="photo.jpg" alt="A photograph">

INCORRECT HTML:

<br></br>
<img src="photo.jpg" alt="A photograph"></img>

IMPORTANT:

In HTML, a trailing slash is unnecessary for void elements.

For example:

<br>

and

<br />

are accepted by HTML parsers, but the slash in <br /> does
not make it an element with a closing tag.

C. BLOCK AND INLINE DISPLAY

Traditionally, beginner tutorials classify many elements as
block-level or inline elements.

BLOCK-LIKE ELEMENTS:

Common examples include:

<div>
<p>
<h1>
<section>

They commonly begin on a new line in the browser's default
styling.

INLINE-LIKE ELEMENTS:

Common examples include:

<span>
<a>
<strong>
<em>

They commonly flow within the surrounding line of text.

IMPORTANT:

Block and inline describe common display behavior, not the
fundamental HTML category of an element.

CSS can change an element's display behavior. Modern HTML
also uses semantic categories such as phrasing content and
flow content.

11. HTML COMMENTS
------------------------------------------------------------

Comments allow developers to add notes to HTML source code.

SYNTAX:

<!-- Your comment goes here -->

EXAMPLE:

<!-- Main heading -->
<h1>HTML Basics</h1>

<!-- Introduction paragraph -->
<p>HTML defines the structure of web content.</p>

MULTILINE COMMENT:

<!--
This is a multiline comment.
It can contain several lines of notes.
-->

IMPORTANT:

- Comments are not displayed as ordinary page content.
- Comments can help organize source code.
- Comments are not a security feature.
- Avoid placing sensitive information inside comments.

12. HTML NESTING AND INDENTATION
------------------------------------------------------------

A. NESTING

Nesting means placing one element inside another element.

EXAMPLE:

<div>
    <h1>My Website</h1>
    <p>Welcome to my website.</p>
</div>

Here:

- div is the parent element.
- h1 and p are child elements.
- h1 and p are siblings.

B. CORRECT NESTING

<p>This is <strong>important</strong> text.</p>

The strong element opens and closes inside the paragraph.

C. INCORRECT NESTING

<p>This is <strong>important text.</p></strong>

The tags are improperly nested.

CORRECT VERSION:

<p>This is <strong>important text</strong>.</p>

D. INDENTATION

Indentation means adding spaces at the beginning of lines
to make the structure easier to understand.

EXAMPLE:

<html>
    <head>
        <title>My Website</title>
    </head>

    <body>
        <h1>Welcome</h1>
        <p>Hello World.</p>
    </body>
</html>

BENEFITS:

- Improves readability.
- Makes parent-child relationships easier to identify.
- Helps developers find errors.
- Makes large projects easier to maintain.

IMPORTANT:

Indentation improves readability, but spaces and line breaks
do not generally determine HTML structure in the way they
do in some programming languages.

13. HTML FILE CREATION AND EXECUTION
------------------------------------------------------------

You can write HTML using a text editor or a code editor.

COMMON TOOLS:

- Visual Studio Code
- Notepad
- Other text editors
- Browser-based HTML editors

STEPS:

STEP 1:
Create a folder for your project.

Example:
my-website

STEP 2:
Open the folder in your code editor.

STEP 3:
Create a new file.

Example:
index.html

STEP 4:
Write the following code.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My First Website</title>
</head>
<body>
    <h1>Hello World</h1>
    <p>I am learning HTML.</p>
</body>
</html>

STEP 5:
Save the file.

STEP 6:
Open index.html in a web browser.

STEP 7:
To see your changes, save the file and refresh the browser.

IMPORTANT:

The file extension must be .html.

For example:

index.html     Correct
index.txt      Not an HTML file by extension
index.html.txt Usually a text file, not an HTML file by extension

14. IMPORTANT RULES AND BEST PRACTICES
------------------------------------------------------------

1. Always begin a modern HTML document with:

   <!DOCTYPE html>

2. Use lowercase tag and attribute names by convention.

3. Use meaningful document titles.

4. Include character encoding:

   <meta charset="UTF-8">

5. Include viewport settings for responsive pages:

   <meta name="viewport" content="width=device-width, initial-scale=1.0">

6. Use the lang attribute:

   <html lang="en">

7. Close elements that require closing tags.

8. Nest elements correctly.

9. Use indentation to improve readability.

10. Use meaningful heading levels.

11. Provide useful alternative text for meaningful images.

12. Use CSS rather than HTML spacing tricks for layout.

13. Use semantic HTML elements when they match the purpose
    of the content.

14. Keep the document structure clear and consistent.

15. Validate HTML when you need to check for markup errors.

16. Do not use HTML alone when you need complex interactivity
    or application logic; use JavaScript where appropriate.

17. Remember that HTML defines structure and meaning, while
    CSS controls presentation and JavaScript adds behavior.

18. Learn to write HTML before relying heavily on frameworks.

15. COMPLETE EXAMPLE
------------------------------------------------------------

Create a file named:

index.html

WRITE THIS CODE:

<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">

    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <meta name="description"
          content="A beginner's introduction to HTML.">

    <title>HTML Chapter 1</title>
</head>

<body>

    <!-- Main heading -->
    <h1>Welcome to HTML</h1>

    <!-- Introduction -->
    <p>
        HTML stands for HyperText Markup Language.
        It defines the structure of web pages.
    </p>

    <hr>

    <!-- Another section -->
    <h2>Why Learn HTML?</h2>

    <p>
        HTML is the foundation of web development.
        It works with CSS and JavaScript to build websites.
    </p>

</body>

</html>


UNDERSTANDING THE EXAMPLE:

<!DOCTYPE html>
Declares modern HTML.

<html lang="en">
Starts the root element and identifies the document language.

<head>
Contains metadata and resources.

<meta charset="UTF-8">
Specifies the character encoding.

<meta name="viewport" ...>
Provides viewport settings for mobile-friendly rendering.

<meta name="description" ...>
Provides a description of the page.

<title>HTML Chapter 1</title>
Sets the document title.

<body>
Contains the main page content.

<!-- Main heading -->
Adds a source-code comment.

<h1>
Defines the main heading.

<p>
Defines a paragraph.

<hr>
Represents a thematic break.

<h2>
Defines a second-level heading.

</html>
Closes the root element.

16. CHAPTER SUMMARY
------------------------------------------------------------

HTML:
The standard markup language for structuring web content.

<!DOCTYPE html>:
Declares modern HTML and helps enable standards mode.

<html>:
The root element of the document.

<head>:
Contains metadata and resources.

<meta>:
Provides metadata, such as character encoding.

<title>:
Defines the document title.

<body>:
Contains the main content of the page.

<h1> to <h6>:
Represent six heading levels.

<p>:
Defines a paragraph.

<br>:
Creates a line break.

<hr>:
Represents a thematic break.

<!-- -->:
Creates a comment.

ATTRIBUTE:
Provides additional information or configuration.

ELEMENT:
The complete HTML structure represented by its markup.

NESTING:
Placing one element inside another element.

INDENTATION:
Formatting code to make its structure easier to read.

VOID ELEMENT:
An element that cannot contain child elements and has no
closing tag.
